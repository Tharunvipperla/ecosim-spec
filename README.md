# ECOSIM — Technical Specification

A mechanistic, conservation-exact ecosystem simulation: a plant carbon economy on a
multi-nutrient soil with 3D light and root competition, water and hydraulics, phenology
and seed/seedling banks, disturbance and fire, demography with density dependence — and a
heterotroph layer on top (general condition/health, herbivory with a growth–defense
trade-off, a two-tier consumer interface with six tissue attacks, and discrete mobile
animal agents across a second predator trophic level).

**Read the spec:** https://tharunvipperla.github.io/ecosim-spec/

Every gram of matter moves through a conservation ledger; every new mechanism is added
off-by-default and stays bit-identical to a golden reference oracle. This repository hosts
the rendered specification only.
